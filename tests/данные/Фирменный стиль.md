# Фирменный стиль роликов

Настраивается один раз. Дальше движок берёт всё отсюда, и каждый новый ролик выходит
в одном виде. Меняете значение здесь: меняется во всех будущих роликах.

Ниже обычный текст, где слева название, справа значение. Правьте только правую часть,
отступы слева не трогайте.

```yaml
формат:
  ширина: 1080
  высота: 1920
  кадров_в_секунду: 30      # один на весь конвейер: тело, финал, обложка

субтитры:
  стиль: тень               # тень (белый текст с мягкой тенью) | плашка (тёмная подложка)
  позиция: 0.16             # доля высоты до верха блока: 0.16 сверху, 0.74 снизу
  шрифт: Unbounded.ttf
  размер: 48
  высота_строки: 72
  символов_в_строке: 20
  строк_максимум: 2
  пауза_новой_фразы: 0.7    # секунд тишины, после которых начинается новая фраза
  цвет_текста: "#FFFFFF"
  цвет_активного_слова: "#FFD23F"   # слово, которое звучит прямо сейчас

финал:
  подпись: ""               # что появляется в конце: имя, название канала. Пусто: финала нет
  шрифт: Unbounded.ttf
  цвет: "#FFD23F"
  хвост: 1.0                # секунд стоп-кадра после конца речи
  начало_до_конца: 2.0      # за сколько секунд до конца тела появляется подпись
  звук_в_кадре: true        # подпись синхронизируется со звуком из съёмки (выдох, хлопок, слово)
  звук_на_секунде: 1.4      # локальное время этого звука внутри куска финала

обложка:
  позиция: 0.40             # доля высоты до верха названия: 0.40 центр кадра, 0.56 нижняя половина
  длительность: 2.2         # секунд в начале ролика
  затухание: 0.4
  шрифт_основной: Unbounded.ttf
  шрифт_акцента: CormorantGaramondItalic.ttf
  цвет_основной: "#F5F0E1"
  цвет_акцента: "#FFD23F"
  стикеры: false            # true, если в assets/stickers лежат свои картинки

музыка:
  громкость: 0.05           # подложка под речь, 0 отключает
  режим: pad

монтаж:
  кадрирование: лицо        # лицо: обрезка 9:16 следует за лицом по планам | центр: середина кадра
  зум: 0.08                 # «дыхание» кадра: 0.04 не видно, 0.08 заметно, 0 отключает
  дед_эйр: 0.8              # пауза длиннее этого считается мёртвой и подбивается
  беречь_начало: 0.7        # секунд в начале куска, которые не режем: там хук
  беречь_конец: 0.5

распознавание:
  модель: small             # small для черновика, medium для проверки готового
  язык: ru
  словарь: {}               # частые ошибки распознавания: "как слышит": "как правильно"
```

## Как заполнять словарь распознавания

Распознавание регулярно калечит имена, названия и термины: слышит «промтов» вместо
«промпты», «Неронка» вместо «Нейронка». Каждую такую ошибку один раз вносите в словарь,
и она перестанет появляться:

```yaml
  словарь:
    промтов: промпты
    Неронка: Нейронка
```

Словарь под конкретного автора: ваше имя, название вашего дела, ваши термины. Это
самая быстрая настройка с самым заметным эффектом.

## Что здесь может устареть

- подпись финала, если сменилось название канала или имя;
- цвета и шрифты при смене фирменного стиля;
- словарь распознавания растёт постоянно, это нормально.
